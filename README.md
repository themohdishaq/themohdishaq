## 👋 About Me

I'm **Muhammad Ishaq**, a Full-Stack Software Engineer and technology entrepreneur focused on building practical digital products, scalable web platforms, and AI-powered applications.

I enjoy working across the product lifecycle—from architecture and backend APIs to user interfaces, databases, integrations, and deployment.

- 💻 **Full-stack engineering:** Modern web applications, APIs, databases, and production deployments.
- 🤖 **AI & intelligent systems:** Agentic AI, retrieval-augmented generation (RAG), and AI-enabled workflows.
- 🚀 **Product building:** Turning ideas into useful, maintainable digital products.
- 🧩 **Problem solving:** Connecting technology, research, and real-world needs.
- 🌱 **Currently exploring:** Better AI systems, software architecture, and developer tooling.
