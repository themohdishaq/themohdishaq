I enjoy working across the product lifecycle—from architecture and backend APIs to user interfaces, databases, integrations, and deployment.

- 💻 **Full-stack engineering:** Modern web applications, APIs, databases, and production deployments.
- 🤖 **AI & machine learning:** Agentic AI, retrieval-augmented generation (RAG), LLM integrations, and computer vision.
- ⚙️ **DevOps:** Containerised deployments, CI/CD pipelines, and Linux-based infrastructure.
- 🚀 **Product building:** Turning ideas into useful, maintainable digital products.
- 🧩 **Problem solving:** Connecting technology, research, and real-world needs.
- 🌱 **Currently exploring:** Better AI systems, software architecture, and developer tooling.

## 🎓 Final Year Project — Drone-Based Crop Intelligence

**Drone-Based Crop Disease Detection, Spraying & Phenotyping**

An agriculture technology project combining drone-enabled crop monitoring, machine learning, and an agriculture dashboard to support precision farming.

- 🤖 **Model training:** Trained a machine-learning model for crop disease detection.
- 🚁 **Precision agriculture:** Project scope included drone-assisted crop monitoring and targeted spraying.
- 🗺️ **GPS-enabled dashboard:** Developed an agriculture dashboard with GPS-based calculations and location-aware crop information.
- 🌱 **Crop phenotyping:** Investigated phenotyping in mung bean crops to support crop assessment and analysis.
- 🤝 **Research collaboration:** Conducted in collaboration with the **National Agricultural Research Centre (NARC)**.
- 👩‍🏫 **Supervision:** Supervised by **Dr. Rafia Mumtaz**, Head of Department, Software Engineering.
